# Historical engineering records

The documents under [`slices/`](slices/) preserve dated implementation and
validation records from before Lectern0 became 8vo and before the supporting
repositories were prepared for publication.

They are archival evidence, not current build instructions. Machine-specific
paths have been replaced with placeholders, and historical publication status
has been rewritten so it cannot be mistaken for current repository policy.

For current project information, use the root
[`README.md`](../../README.md), [`DEPENDENCIES.md`](../../DEPENDENCIES.md), and
[`scripts/README.md`](../../scripts/README.md).
